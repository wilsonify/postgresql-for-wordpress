# Test tools

`phpunit.phar` is generated by `scripts/fetch-phpunit.sh` and is ignored by git.
Run `scripts/bootstrap.sh` from the repository root before the test suite:

```sh
./scripts/bootstrap.sh
./tests/tools/phpunit.phar tests/
```

The version and SHA-256 are pinned in `scripts/versions.sh`. Do not commit the
phar; that would reintroduce the vendored binary this directory is meant to
avoid.
